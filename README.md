# 📚 Book Counter App

A simple and interactive web application built as part of a Scrimba JavaScript project. This app allows users to keep track of the number of books they've bought by incrementing a counter and saving cumulative totals.

## 🚀 Features

- **Increment Counter:** Increases the current count by 1.
- **Save Entries:** Adds the current count to a running total of previously saved entries.
- **Reset on Save:** Automatically resets the current counter to 0 after saving.
- **Responsive Design:** Styled with a cozy bookshelf background that adapts to different screen sizes.

## 🛠️ Built With

- **HTML5** - Structure of the app.
- **CSS3** - Styling, layout, and background images.
- **JavaScript (Vanilla JS)** - App logic, DOM manipulation, and event handling.
